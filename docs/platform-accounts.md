# 平台账号（开发预览）

App 的“我的 → 账号管理”和 TV 的“设置 → 账号管理”提供哔哩哔哩、斗鱼、虎牙、抖音四个平台入口。

## 使用

- **导入 Cookie**：粘贴该平台的完整 Cookie。输入默认隐藏，编辑时不回填已有凭据。抖音旧版游客 `ttwid` 可迁移，但不会被标记为已登录。
- **官方网页登录**：App 在 Android、iOS、macOS、安装了 WebView2 的 Windows 上提供平台官方页面。登录后由用户点击完成，按平台域名收集凭据。macOS 最低版本为10.15。Linux 和 TV 可使用 Cookie 或配对接收；B站已有扫码登录继续保留。
- **设备配对**：接收设备选择对应平台的“从其他设备接收”，发送设备在同平台选择“发送到其他设备”。设备须在同一局域网；发送端可扫码或粘贴配对信息，接收端必须确认。二维码两分钟有效、一次性使用。二维码包含临时加密密钥，不包含账号 Cookie；不要把有效配对信息发给其他人。
- **退出**：清理该平台本地凭据及可访问的网页登录 Cookie，不影响其他平台。遇到系统存储或浏览器清理失败会提示重试。Android 网页 Cookie 接口不能枚举从未访问过的任意路径，因此清理覆盖已知官方域名和本次登录访问路径；网页登录清理仍需实机验收。

Windows 网页登录使用应用数据目录中的 `WebView2` 配置，登录页面、会话读取和退出清理共用此环境。程序安装在 `Program Files` 时无需管理员权限，也不会尝试在安装目录创建浏览器数据。组件启动和网页加载有独立进度及超时重试；网页实际加载完成后才启用“完成登录”。旧 B站网页登录路由也使用这一实现，扫码入口保留。

## 状态与能力边界

| 状态 | 含义 |
| --- | --- |
| 未配置 | 没有该平台账号凭据 |
| 已配置，待验证 | 凭据已接入请求，尚无可确认的身份验证结果 |
| 已验证 | 身份验证接口确认有效，可展示账号信息 |
| 已失效 | 平台明确拒绝账号或删除登录凭据 |
| 暂时无法验证 | 网络或接口暂时不可用，不等同于退出登录 |
| 仅本次会话 | 系统安全存储不可用，关闭 App 后需要重新登录 |

当前只有 B站实现了身份接口验证。斗鱼、虎牙、抖音保守显示已配置，不能根据 Cookie 字段存在就宣称验证成功。网页登录入口和取流请求已接入，但它们在各平台真实设备上的登录完成、风控和账号权限仍需实测。

虎牙会话导入兼容旧版 `udb_l`，以及当前官方网页使用的 `udb_uid` 与 `udb_biztoken` 组合。单独的用户编号、游客标识或不完整组合不会被当作可导入会话；识别并保存后仍显示“已配置待验证”。

斗鱼的 Cookie 用于官方取流请求并与签名设备标识一致。此前单房间实测中，登录后的原画固定连接连续解码约30分钟；匿名对照约300秒结束。这不能推导出所有房间、线路和账号均永久有效。虎牙 Cookie 用于 HTTPS 房间发现；原有 HTTP TARS 播放路径仍为匿名请求，不会向其发送凭据，也不保证登录后解除画质限制。

## 播放行为

移除斗鱼固定四分钟切换播放器。只有返回正数过期时间的当前线路会提前获取一次新地址，正常播放不会因为定时器或返回前台而重开。`expire=0` 和未知有效期不启动定时更新，`expire=0` 也不代表永久有效。

断流后使用近期预取或新请求取得的地址，限制重试次数；只有明确确认房间未开播才显示未开播。画质优先显示实际返回结果。显式更换账号、画质或线路会重新取流；仅验证账号、服务器轮换 Cookie 不会定时重启播放器。

## 凭据保存与传输

`simple_live_account` 统一负责四平台状态、版本隔离、安全存储和旧配置迁移。凭据使用系统安全存储；安全存储不可用时保留在内存中，不降级为普通配置文件。删除失败时写入本机恢复阻断标记，防止下次启动恢复已经退出的账号。

普通 WebDAV 备份和设置同步排除凭据及恢复阻断标记。恢复设置保留本机账号状态。旧备份中的 B站账号仅在用户显式勾选时导入。旧版明文账号 HTTP/远程同步入口已关闭，统一改为一次性 AES-GCM 加密配对；回执也加密认证并绑定本次发送请求。

HTTP 日志不记录请求或响应正文、Cookie 和 Authorization。核心日志会脱敏平台凭据与签名 URL。单平台 Cookie 只发往匹配的平台域名，认证请求不自动跨域重定向。

## 验证与待验收

自动测试使用合成凭据，覆盖账号迁移、验证竞态、退出失败保护、服务器 Cookie 更新、域名隔离、日志脱敏、配对篡改/过期/重放、确认与取消、普通备份排除账号，以及播放器命令排序和预取策略。

App 与 TV 提交依赖锁文件，CI 强制按锁定结果解析，避免构建时自动更新到不兼容的原生插件。Linux/macOS 产物使用保留执行权限的 tar.gz 打包。

GitHub Actions `Platform accounts validation` 运行核心、共享包、App 和 TV 测试，并尝试 Windows/macOS/Linux release 构建、App/TV Android debug APK、iOS 无签名构建。构建产物用于开发验证，不代表已发布正式版本；Android debug APK 不能覆盖使用其他签名的正式安装包。iOS 无签名构建不可直接安装。

Windows CI 还通过 `flutter drive` 运行原生 WebView2 冒烟测试：复用网页登录的环境初始化入口，等待原生视图创建后加载本地 HTML，检查加载回调、JavaScript、截图像素及关闭后重新打开。测试不使用真实账号或平台网络，报告与截图保存为 `accounts-windows-webview-smoke` 产物；缺少 WebView2 Runtime 时会失败，不会跳过。可在安装了 WebView2 Runtime 的 Windows 上进入 `simple_live_app`，运行 `flutter drive -d windows --driver=test_driver/windows_webview_smoke_driver.dart --target=integration_test/windows_webview_smoke_test.dart --dart-define=INTEGRATION_TEST_SHOULD_REPORT_RESULTS_TO_NATIVE=false`。

实机验收仍包括：各端官方网页登录、安全存储重启恢复、单平台退出隔离、TV 遥控器确认、跨设备配对，四平台真实账号取流，以及斗鱼 Windows 原画长时间观看、切房间、前后台和断网恢复。编译通过不等于这些体验已经通过。
